# Segurança

Esta é uma prévia local de desenvolvimento, não uma certificação ou serviço multiusuário exposto à rede. Leia [docs/SECURITY_MODEL.md](docs/SECURITY_MODEL.md).

Não anexe credenciais, banco privado, arquivos de ambiente ou transcrições completas a issues. Use Private Vulnerability Reporting quando habilitado. Caso não esteja disponível, peça um canal privado sem divulgar detalhes de exploração. Não há SLA prometido nesta fase.

Dependências precisam de revisão e CI. Uma auditoria sem alertas conhecidos não prova ausência de vulnerabilidades.

Quatro números.
Quatro significados.

O painel começa vazio. Zero só aparece quando existe uma observação de zero.

01 / Consumo

Recibo final importado por chamada. Entrada inclui cache; saída pode incluir raciocínio. Não lemos suas credenciais ou conversas.

02 / Cache

Reuso informado pelo provedor. Escritas podem ter tarifa própria. O benefício não é atribuído automaticamente ao BBrainX.

03 / Redução

Diferença entre candidatos e pacote local. Não é baseline de tarefa, inferência evitada nem qualidade garantida.

04 / Custo

Valor informado e estimativa por tarifa ficam separados. Moedas não são convertidas. Energia, taxas e assinaturas não são inferidas.

Como alimentar este painel

Importe somente metadados finais por chamada. Não importe prompts, respostas, cabeçalhos ou tokens de autenticação.

node scripts/usage.mjs import --project ID --file recibos.json
node scripts/usage.mjs compare --project ID --file par.json
node scripts/usage.mjs report --project ID

Contrato, exemplos e limites: docs/observatory/README.md. A importação explícita registra a origem; não autentica uma fatura ou um benchmark.

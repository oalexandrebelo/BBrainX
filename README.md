# BBrainX · GODMODCODE

Local-first context, memory and verified handoffs for coding agents.

Implementation and reproducible validation are being assembled in this repository. No model-performance, platform-support or token-savings claim is made before evidence exists.

The first release targets macOS, with a portable Node.js core, SQLite persistence, an MCP interface, and an interactive React Flow architecture explorer.

Existing Codex / Claude Code / Antigravity authentication and gateways remain unchanged.
